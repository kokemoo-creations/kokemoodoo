FlagShip Shipping Integration

This module provides integration with FlagShip shipping API for Odoo Community Edition.

Features

  • Real-time shipping rate calculation
  • Shipping label generation
  • Tracking number integration

Configuration

  1. Go to Inventory > Configuration > Delivery Methods
  2. Create or edit a delivery method
  3. Set Provider to FlagShip
  4. Enter your API credentials in the new fields
  5. Test in Test Environment before Production
Note: Replace the example API endpoint (https://api.shippingapi.com/v1/rates) with FlagShip's actual API endpoint in the code.
